# Behavior specs

Specs describe **observable** behavior for this fork. Each spec has:

- ID: `SPEC-<area>-<nnn>` (example: `SPEC-KV-001`)
- Statement: what must hold
- **Verified by**: test path(s) that prove it
- Optional link to a contract under `docs/contracts/`

When changing behavior, update the spec in the same change set as the code and test.
